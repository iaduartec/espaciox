Regalos

Cada celebración es una oportunidad para crear recuerdos únicos. Elige un detalle especial para tus invitados.

Libro de firmas cumpleaños infantil

Portadas coloridas, ilustraciones personalizables y páginas gruesas para que los peques firmen, dibujen y peguen pegatinas.

Incluye: espacio para el nombre de cada invitado, sección de fotos instantáneas y bolsillos para pequeños recuerdos.

Pedir para mi evento

Libro de recuerdos comunión

Diseño sobrio con detalles en dorado, portada dura y guardas de tela para conservar fotos, lecturas y dedicatorias.

Incluye: fichas para invitados, sobre para estampa, apartado de agradecimientos y páginas libres para pegar recuerdos.

Reservar unidades

Libro de firmas jubilación

Formato elegante con lomo cosido, páginas numeradas y cintas separadoras para que cada colega deje su mensaje favorito.

Incluye: portada personalizada con el nombre de la persona homenajeada, sección de hitos laborales y espacio para fotografías del equipo.

Solicitar personalización

Cuaderno “Dibuja conmigo” para peques y padres

Retos creativos por edades, páginas desprendibles y papel grueso para lápices de colores, rotuladores y acuarelas ligeras.

Incluye: láminas de colorear con escenas del espacio, juegos de unir puntos y espacios para dedicatorias compartidas.
